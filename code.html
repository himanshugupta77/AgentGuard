Pipeline Interception

How AgentGuard Intervenes

Every tool payload is intercepted at the network/socket boundary before execution.

01 / DISPATCH
🤖

AI Agent

Autonomous model formulates tool invocation schema (e.g. bash, fs_write, sql_exec).

02 / INTERCEPT
🛡️

AgentGuard Engine

Inspects parameter semantics, checks stateful context, path safety, and evaluates risk score.

03 / DECISION
⚖️

3-Way Policy

✔ ALLOW (Instant) ❓ ASK (2-Factor/Slack) ⛔ BLOCK (Isolated)
04 / EXECUTION
💻

System Tools

Only validated and sanitized operations touch the host machine, file system, or live DB.

Dynamic Scoring

Deterministic Three-Tier Evaluation

Calculated in under 4ms using semantic heuristics, parameter ASTs, and target reputation.

ALLOW Risk Score: 0 – 29

Low Impact Operations

Read-only file queries, public documentation web scraping, safe linting commands, non-mutating search queries.

Execution Latency: < 1.2ms
ASK (HUMAN REVIEW) Risk Score: 30 – 69

Ambiguous Mutations

Bulk rename of files, outbound webhooks with novel payloads, modification of config files, high-cost LLM sub-delegation.

Verification Hook: Slack / Webhook 2FA
BLOCK Risk Score: 70 – 100

Catastrophic Actions

Recursive deletions (`rm -rf`), reading SSH keys or `.env`, dropping database tables, network socket binds to blacklisted IPs.

Containment: Instant Hard Trap
MAX 100
